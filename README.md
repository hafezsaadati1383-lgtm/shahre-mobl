# شهر مبل | Shahre Mobl

## فارسی

یک صفحه‌ی فرود (Landing Page) برای فروشگاه اینترنتی مبلمان، طراحی و پیاده‌سازی‌شده با HTML و CSS خالص (بدون فریم‌ورک).

### امکانات
- منوی ناوبری بالای صفحه با افکت hover
- بخش معرفی (Hero Section) با تصویر پس‌زمینه و افکت backdrop-blur
- گالری دسته‌بندی محصولات با افکت hover نمایش توضیحات
- بخش محصولات ویژه با قیمت قبل/بعد از تخفیف
- بخش نظرات خریداران
- فوتر کامل با لینک‌های سریع، اطلاعات تماس و شبکه‌های اجتماعی
- طراحی کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- پشتیبانی کامل از راست‌به‌چپ (RTL) برای زبان فارسی

### تکنولوژی‌ها و ویژگی‌های CSS استفاده‌شده
- **Flexbox** و **CSS Grid** برای چیدمان بخش‌های مختلف
- تابع `clamp()` برای تایپوگرافی و فاصله‌های ریسپانسیو بدون نیاز به مدیا کوئری زیاد
- `transition` و افکت‌های `hover` برای تعاملات بصری
- `backdrop-filter: blur()` برای افکت شیشه‌ای روی بخش معرفی
- فونت‌های فارسی سفارشی (Vazir / Vazirmatn) با `@font-face`
- آیکون‌های Font Awesome و SVG سفارشی برای شبکه‌های اجتماعی

## English

A furniture e-commerce landing page built with pure HTML and CSS (no frameworks).

### Features
- Top navigation menu with hover effects
- Hero section with background image and backdrop-blur effect
- Product category gallery with hover-reveal descriptions
- Featured products section with before/after discount pricing
- Customer reviews section
- Full footer with quick links, contact info, and social media icons
- Fully responsive design (mobile, tablet, desktop)
- Full RTL (right-to-left) support for Persian language

### Technologies & CSS Features Used
- **Flexbox** and **CSS Grid** for layout structure
- `clamp()` for responsive typography and spacing with minimal media queries
- `transition` and `hover` effects for visual interactions
- `backdrop-filter: blur()` for the glass-effect hero overlay
- Custom Persian fonts (Vazir / Vazirmatn) via `@font-face`
- Font Awesome icons and custom SVG icons for social media links
